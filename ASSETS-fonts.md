# Fonturi locale VELORA

Fonturile sunt găzduite local; pagina nu trebuie să contacteze Google Fonts.

- Manrope variable normal, greutăți 200–800: `assets/fonts/manrope-latin.woff2` și `manrope-latin-ext.woff2`.
- Cormorant Garamond variable normal, greutăți 300–700: `assets/fonts/cormorant-garamond-latin.woff2` și `cormorant-garamond-latin-ext.woff2`.
- Subseturile latin și latin-ext includ caracterele românești ă, â, î, ș, ț și majusculele lor.
- Declarațiile `@font-face`, intervalele Unicode și `font-display: swap` sunt în `assets/css/fonts.css`.
- Licențe SIL Open Font License 1.1: `assets/fonts/Manrope-OFL.txt` și `assets/fonts/Cormorant-Garamond-OFL.txt`.

Sursa: Google Fonts CSS API (Manrope v20 și Cormorant Garamond v21), descărcate la 22 octombrie 2026. Răspunsul original este păstrat în `assets/fonts/google-fonts-source.css` exclusiv pentru proveniență; site-ul trebuie să încarce numai CSS-ul local din `assets/css/fonts.css`.
